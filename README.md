# Покупилла — Telegram Mini App

Готовая статическая витрина для Telegram Mini App. Каталог собран из файла `data/source.html`.

## Что уже есть
- 91 позиции из исходного прайса;
- поиск по названию/бренду;
- фильтры по бренду, категории, цене, RAM, памяти, состоянию и eSIM;
- сортировка по цене и названию;
- карточка товара с характеристиками;
- кнопка «Уточнить наличие» через `Telegram.WebApp.sendData()`;
- светлая/тёмная тема через тему Telegram;
- оранжевая визуальная система;
- haptic/BackButton-совместимость с Telegram WebApp API;
- `tools/parse_prices.py` для повторного импорта обновлённого HTML-прайса.

## Запуск локально
Нужен обычный статический сервер, например:

```bash
python -m http.server 8080
```

Открой `http://localhost:8080` в браузере. Для Telegram Mini App нужен HTTPS URL.

## Подключение к Telegram
1. Создай бота через @BotFather.
2. Создай Mini App и укажи HTTPS URL этого проекта.
3. Если приложение запускается из inline/keyboard-кнопки бота, `sendData()` передаст выбранный товар боту.
4. На сервере бота обработай JSON с `action: product_request`.

## Обновление каталога
Положи новый HTML-прайс вместо `data/source.html` и выполни:

```bash
python tools/parse_prices.py data/source.html data/catalog.json
```

После этого обнови `catalog.js` из `data/catalog.json` (или замени его небольшим build-скриптом).

## Важно
Цены и названия в приложении отражают исходный файл, включая позиции б/у и повторяющиеся строки. Перед публикацией магазина стоит добавить реальные фотографии товаров и проверить актуальность цен/наличия.
